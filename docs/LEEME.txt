SD COMAYAGUA POS

Esta carpeta contiene una app web/PWA lista para usar como sistema básico de inventario, catálogo, cotizaciones y ventas.

ARCHIVOS IMPORTANTES:
- app.html: abre el sistema.
- js/config.js: configuración del negocio, Sheet ID, URL de Apps Script y nombres de hojas.
- apps-script/Code.gs: código para pegar en Google Apps Script.
- SD_COMAYAGUA_PLANTILLA_ACTUALIZADA.xlsx: plantilla Excel/Google Sheets.

PASO RÁPIDO:
1. Sube la plantilla a Google Drive o usa tu Google Sheet actual.
2. Abre Google Apps Script.
3. Pega Code.gs.
4. Publica como Web App.
5. Copia la URL terminada en /exec.
6. Abre la app, entra a Configuración y pega la URL.
7. Prueba conexión.

IMPORTANTE:
No se cambió el Sheet ID obligatorio.
No se renombraron las hojas principales.
Las columnas nuevas son opcionales y van al final.
