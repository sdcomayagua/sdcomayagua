# Cargar productos

## Desde la app

1. Entra a Inventario.
2. Presiona **+ Producto**.
3. Llena código, nombre, precio y stock.
4. Usa colores si aplica: `Negro=5; Azul=2`.
5. Guarda.
6. Sincroniza.

## Desde Google Sheets

1. Abre `productos_pos`.
2. Agrega una fila con las columnas principales.
3. Conserva el código único.
4. No insertes columnas en medio.
5. En la app, entra a Sincronización y descarga productos.

## Desde JSON

1. En Configuración presiona **Importar productos**.
2. Selecciona un JSON con lista de productos.
3. Revisa el inventario.
4. Sincroniza.
