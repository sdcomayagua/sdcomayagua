# Uso diario

## Vender

1. Entra a Catálogo.
2. Toca **Vender** en el producto.
3. Revisa el carrito.
4. Escribe cliente y teléfono.
5. Activa COD si aplica.
6. Presiona **Registrar venta**.
7. Comparte el recibo por WhatsApp.

## Cotizar

1. Entra a Catálogo.
2. Toca **Cotizar**.
3. Revisa el carrito.
4. Presiona **Crear cotización**.
5. Envia por WhatsApp.

## Inventario

- Edita productos desde Inventario.
- Usa +1 o -1 para ajustes rápidos.
- Desactiva productos en lugar de eliminarlos.
- Usa formato `Color=Stock` para variantes.

## Respaldo

En Configuración usa **Exportar respaldo** al menos una vez al día.
