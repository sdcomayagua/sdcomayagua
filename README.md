# Gamer Comayagua · GitHub Pages + Google Sheets

Sitio web responsive para tienda gamer, catálogo, carrito, cotizaciones, Tigo Money, pago al recibir por producto y administración con Apps Script.

**Empezá por [LEEME_PRIMERO.md](LEEME_PRIMERO.md)**. Ahí está el Google Sheets real ya creado y los pasos para conectar Apps Script y publicar en GitHub Pages.

> Este paquete no debe considerarse conectado a Google Sheets hasta completar la implementación de Apps Script y agregar la URL `/exec` a `assets/js/config.js`.
