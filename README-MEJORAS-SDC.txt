Qué mejora esta versión:
1. Modal de Cotización/Ventas más ordenado en celular.
   - Botones inferiores más claros.
   - Secciones rápidas: Productos, Lista, Cliente/envío y Factura.
   - La lista de productos seleccionados queda más visible.

2. Factura/Cotización más limpia para cliente.
   - Diseño más blanco, premium y legible.
   - Mejor composición para imprimir PDF.
   - Botón PDF usa una impresión mejorada con estilos propios.

3. Fotos de productos más visibles.
   - Las imágenes ya no se cortan con object-fit: cover.
   - Se muestran completas en tarjetas, selector, miniaturas y factura.

4. Entrega y municipio/departamento.
   - Mantiene los 18 departamentos y municipios en select.
   - Si el departamento es Comayagua o La Paz, sugiere Domicilio.
   - Para otros departamentos, sugiere Forza/C807/Cargo Expreso.

5. No se reescribió toda la app.
   - Se agregó una capa final de mejora para no romper inventario, ventas, guardados, respaldo ni importación.

Cómo subir:
1. Sube todos los archivos del ZIP a GitHub Pages reemplazando los anteriores.
2. Asegúrate de que estén incluidos:
   - css/sdc-ventas-hotfix.css
   - js/sdc-ventas-hotfix.js
3. Abre la página en modo incógnito o borra caché si no ves cambios.
