# Fotos del catálogo público

Las imágenes de esta carpeta se preparan automáticamente desde las fotos públicas
del inventario. Permiten descargar catálogos en PNG y PDF sin depender de los
permisos de lectura de imágenes de otros servidores.

La relación entre cada producto, su foto original y esta copia se publica en
`data/catalogo-fotos.json`. Cambiá la foto desde el inventario; la sincronización
actualiza la copia. Los precios, costos y existencias no se guardan aquí.
